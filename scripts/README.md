# Development & Automation Scripts (`scripts/`)

This directory contains cross-platform developer utilities, local validation scripts, and monorepo maintenance tools.

---

## 📄 Scripts Overview

- **`dev-setup.sh`**: Bash script to verify prerequisite runtimes (Node.js, Python, Java, Docker) on Linux / macOS / WSL.
- **`dev-setup.ps1`**: PowerShell script to verify prerequisites on Windows environments.

---

## 🛠️ Usage

### Run on Linux / macOS / Git Bash
```bash
./scripts/dev-setup.sh
```

### Run on Windows PowerShell
```powershell
.\scripts\dev-setup.ps1
```
